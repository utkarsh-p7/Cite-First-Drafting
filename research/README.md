# research/v1: frozen dissertation results

Everything here is a byte-for-byte copy of the outputs evaluated in the MSc dissertation
(WMG, University of Warwick, 2026). It is the ground truth the regression tests check the
ported package against, and what the `replay` provider serves in the demo.

| Folder | Contents |
|---|---|
| `outputs/contexts/` | the 40 assembled contexts + rendered prompts (deterministic, regenerated by the tests) |
| `outputs/tool/` | 40 evidence-linked drafts, evidence maps, structure checks, run log |
| `outputs/baseline/` | 40 unlinked baseline drafts, structure checks, run log |
| `outputs/variance_check/` | the second run of C001 and C004 used for the run-to-run variance note |
| `results/` | scoring outputs (`results_task2.md`, `results_per_case.csv`, timing) and the metric rubric |

Frozen run: Groq `openai/gpt-oss-120b`, temperature 0, seed 42, Groq free tier (cost 0.00).
Do not edit anything in this folder. v2 results live in `research/v2/` and never overwrite v1.
